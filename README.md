# 향후 1개월 주요 일정

<https://tskang89.github.io/econ-calendar/>

오늘부터 **한 달 뒤 같은 날**까지의 통화정책 결정일과 지표 발표일을 한 장에
모읍니다. 평일 새벽에 `build/make.py` 가 새로 만들어 되커밋합니다. 독일 조간
브리핑 맨 아래 '참고자료'에 링크로 걸립니다.

[주요국 경제 차트팩](https://tskang89.github.io/euro-chartpack/)에서 떼어
냈습니다. 떼어낼 때 차트팩은 주간 갱신이었고 이쪽은 날마다 바뀌어 한 저장소에 두면
되커밋이 엉켰고, 주소도 차트팩 밑이라 일정만 따로 건네기가 어려웠습니다.
옛 주소(`euro-chartpack/calendar.html`)는 이리로 넘겨 보냅니다.

## 무엇을 싣는가

**통화정책 결정·GDP·소비자물가는 굵게** 뽑습니다. '물가'를 글자 그대로
잡으면 생산자·수입·도매·서비스 물가까지 걸려 마흔 남짓 가운데 열여덟이
굵어집니다 — 그쯤 되면 강조가 아니라 배경입니다. 금리를 움직이는 것은
소비자물가이므로 거기로 좁혔습니다.

**일정이 있는 날만 싣습니다.** 빈 날도 '없습니다'로 두면 한 달 치에서 빈
칸이 스무 개 넘게 깔려 정작 있는 날이 묻힙니다.

## 어디서 받아 오는가

자동으로 받아 오는 곳은 여섯입니다.

| 출처 | 무엇 | 어떻게 |
|---|---|---|
| ECB | 이사회·통화정책회의 | 공식 일정표의 `<dt>/<dd>` |
| 미국 연준 | FOMC | `fomccalendars.htm` 의 `fomc-meeting__month`·`__date` |
| 영란은행 | MPC 발표일 | upcoming-mpc-dates 본문 |
| 한국은행 | 금통위 통화정책방향 | 연도별 목록 `listYear.do` (올해·내년) |
| Eurostat | 유로지역 주요 지표 발표일 | 일정표가 쓰는 `o/calendars/eventsJson` 종점 |
| 독일 통계청 | 지표 발표일정 | Veröffentlichungskalender 의 `c-result` 블록 |

**폴란드 NBP·체코 ČNB·스위스 SNB·튀르키예 TCMB 의 통화정책 결정일은 손으로
적습니다**(`build/policy_dates.py`). 네 곳 모두 자동 수집이 막혀 있습니다 —
NBP 는 봇 차단, ČNB·SNB 는 자바스크립트 렌더링, TCMB 는 리디렉션. 결정일은
한 해에 한 번 공표되고 좀처럼 바뀌지 않으므로, 네 나라 페이지를 날마다
긁는 것보다 이쪽이 오히려 덜 깨집니다.

그 표에는 **공식 출처에서 확인한 날짜만** 적습니다. 월례라서 그럴 것 같다는
식으로 채우지 않습니다. 남은 일정이 75일 안쪽이거나 비어 있으면 빌드가
로그에 경고를 냅니다 — 그때 각 은행 공식 페이지를 보고 채워 넣으십시오.

## 손대기 전에 알아 둘 것

**Eurostat 일정표 페이지는 FullCalendar 로 그려져** 문서만 받아서는 날짜가
한 줄도 없습니다. 그 달력이 값을 받아 오는 종점을 쓰되, **FullCalendar 가
보내는 꼴 그대로** `start`·`end` 를 시간대까지 붙은 ISO 시각으로 주고
`timeZone` 을 함께 보내야 합니다 — `YYYY-MM-DD` 만 주면 HTTP 200 에 본문이
비어서 옵니다(조용한 실패라 특히 조심). `isEuroindicator=true` 로 좁혀
유로지역 주요 지표만 남깁니다.

**연준·영란은행은 날짜에 연도가 붙어 있지 않습니다.** 연준은 `2026 FOMC
Meetings`, 영란은행은 `2026 confirmed dates` 같은 제목 아래 묶여 있을
뿐입니다. 게다가 연준 표는 연도순이 아닙니다(2026 다음이 2025, 2027 이 맨
뒤). 그래서 제목의 **문서 안 위치**로 구간을 갈라 연도를 붙입니다.

**연준은 달을 걸치는 회의를** `Oct/Nov` 에 `31-1` 처럼 적습니다. 결정일은
뒤쪽 달의 1일입니다 — 앞 달을 그대로 쓰면 한 달이 통째로 어긋납니다.
12월/1월은 해까지 넘어갑니다.

**ECB 일정에서** `non-monetary policy meeting` 이 `monetary policy meeting`
을 문자열로 품고 있습니다. 단순히 찾으면 통화정책과 무관한 이사회가 금리
결정일로 올라갑니다. `(?<!non-)` 로 막아 두었습니다.

**연준 FOMC 와 폴란드 NBP 는 이틀 회의**이고 둘째 날 결정을 내므로 그
날짜만 적습니다. 연준의 새 목표범위는 대개 그 다음 날부터 적용됩니다
(2026년 9월 회의는 15–16일, BIS 기준 적용일은 17일).

**독일 통계청은 한 쪽에 여남은 건뿐**이라 한 달 치를 채우려면 쪽을 넘겨야
합니다(`gtp=245710_list%3D<쪽>`). 받은 날짜가 구간을 넘어서면 멈춥니다.

**한국은행 내년 일정 쪽은 연말에야 채워집니다.** 빈 쪽이 오는 것이 정상이라
조용히 건너뜁니다.

## 직접 돌리기

```bash
pip install -r requirements.txt
python build/make.py --check          # 쓰지 않고 만들어만 본다
python build/make.py --date 2026-11-01  # 기준일을 바꿔 본다
python build/make.py                  # index.html 갱신
```
